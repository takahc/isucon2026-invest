# kawasy context

ISUCON2026 優勝者 kawasy（Yoshinori Kawasaki, @kawasy, luvtechno）の公開情報を、AI が参照できる静的コーパス。

**このリポジトリはプライベートです。公開しないでください。GitHub Pages も有効化しないでください。** 他人の番組の全文文字起こしを `private-transcripts/` に含めています。

- 人間向け: `index.html`
- **AI に渡すファイル:** `context.md`（別名 `llms-full.txt`）
- 短い目次: `llms.txt`
- カタログ: `data/sources.json`
- 全文文字起こし: `private-transcripts/`（このプライベートリポジトリに含まれる。公開デプロイや公開リポジトリへは出さない）

JavaScript 不要。

## 著作権

サイトの公開用ページ（`index.html` や各 `pages/`）には、他人の記事全文・番組全文は載せていません。全文は `private-transcripts/` にだけ置いてあります。リポジトリを public にしたり、GitHub Pages を有効にしたりすると、全文が外部から読めるようになるので、どちらも行わないでください。
